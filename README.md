## 5. Mô tả các thư mục chính

- **assets/:** Lưu trữ tài nguyên của ứng dụng như hình ảnh.
- **lib/data/:** Chứa dữ liệu mẫu và các lớp Repository phục vụ việc cung cấp dữ liệu cho ứng dụng.
- **lib/l10n/:** Chứa các tệp hỗ trợ đa ngôn ngữ Tiếng Việt và Tiếng Anh.
- **lib/models/:** Định nghĩa các lớp mô hình dữ liệu.
- **lib/utils/:** Chứa các tiện ích dùng chung trong ứng dụng.
- **lib/viewmodels/:** Xử lý logic và quản lý trạng thái giao diện.
- **lib/views/:** Chứa các màn hình chính của ứng dụng.
- **lib/widgets/:** Chứa các thành phần giao diện có thể tái sử dụng.
- **test/:** Chứa các tệp kiểm thử của dự án.
